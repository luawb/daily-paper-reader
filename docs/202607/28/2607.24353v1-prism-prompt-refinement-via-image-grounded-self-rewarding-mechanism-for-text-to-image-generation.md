## 摘要
文本到图像生成模型能够根据自然语言描述合成高质量图像，但其性能对提示表述高度敏感。现有的提示优化方法主要依赖于文本侧的改写、提示扩展或外部奖励信号，缺乏基于图像的诊断，且难以学习可复用的优化策略。本文提出PRISM框架，即通过图像自奖励机制进行提示优化。PRISM通过结构化视觉诊断来解释生成图像，并从语义一致性、美学质量和人类偏好对齐等方面进行评分，从而闭合提示-图像-反馈循环。它首先通过多任务监督微调初始化一个统一的视觉语言模型，然后通过混合理想点和切比雪夫奖励的自奖励优化来改进提示策略。大量实验表明，PRISM在整体图像质量和细粒度语义对齐方面均有提升，同时为针对性提示优化提供可解释的反馈。代码可在https://anonymous.4open.science/r/PRISM-FF81获取。

## Abstract
Text-to-image generation models can synthesize high-quality images from natural language descriptions, but their performance remains highly sensitive to prompt formulation. Existing prompt optimization methods mainly rely on text-side rewriting, prompt expansion, or external reward signals, offering limited image-grounded diagnosis and weak support for learning reusable optimisation policies. In this paper, we propose PRISM, a Prompt Refinement framework via Image-grounded Self-rewarding Mechanism. PRISM closes the prompt-image-feedback loop by interpreting generated images with structured visual diagnosis and scoring them along semantic consistency, aesthetic quality, and human preference alignment. It first initializes a unified VLM through multi-task supervised fine-tuning, and then improves the prompt policy via self-rewarding optimization with a hybrid ideal-point and Chebyshev reward. Extensive experiments show that PRISM improves holistic image quality and fine-grained semantic alignment, while providing interpretable feedback for targeted prompt refinement. The code is available at https://anonymous.4open.science/r/PRISM-FF81.

### 2. 论文提出的方法论
PRISM框架分为两个关键阶段，核心是一个统一的视觉语言模型（VLM），它同时扮演提示优化器与视觉反馈评估器的双重角色。

**阶段一：多任务监督初始化**
*   **目标**：赋予VLM基础的提示改写和图像评估能力。
*   **数据构建**：构建了四种类型的监督数据：
    1.  **提示改写数据**：从BeautifulPrompt数据集中选取高质量提示对（原始提示 $x$ -> 优化提示 $\hat{x}^*$）。
    2.  **视觉反馈评估数据**：从社区T2I数据源（如DiffusionDB, JourneyDB）中筛选高质量图文对，并通过受控的简化操作，为高质量提示 $\hat{x}$ 构造一个欠详细的对应提示 $x$。对每个提示生成的图像 $I_p$，从**语义一致性、美学质量、人类偏好对齐**三个维度生成结构化诊断文本 $f$ 和评分 $r$。
    3.  **仅评分校准数据**：仅包含评分向量 $r^*$，用于稳定数值评估。
    4.  **反馈引导的改写数据**：给定原始提示、其生成图像及诊断反馈，VLM学习据此生成优化后的提示。
*   **训练方式**：使用以上所有数据，以自回归语言模型损失 $L_{SFT}$ 对VLM进行多任务微调，不同任务有不同损失权重 $\lambda_t$。

**阶段二：自奖励策略优化**
*   **目标**：利用VLM自身产生的视觉反馈作为奖励信号，进一步优化其提示策略。
*   **流程**：
    1.  **采样与生成**：给定用户提示 $x$，当前策略 $\pi_{\theta_{old}}$ 采样 $K$ 个候选优化提示 $\hat{x}_i$，再由冻结的T2I生成器 $G$ 生成对应图像 $I_i = G(\hat{x}_i)$。
    2.  **自反馈评估**：使用一个冻结的VLM副本（阶段一产物）对 $(x, \hat{x}_i, I_i)$ 进行三维度评分，得到奖励向量 $r_i = [r_{sem}, r_{aes}, r_{pref}]$。
    3.  **混合奖励聚合**：为了平衡各维度优化，采用一个创新的混合奖励 $R_i$，结合了两种目标：
        *   **理想点奖励 $R_{ideal}$**：鼓励所有维度的综合得分向完美向量 $r^*=[1,1,1]$ 靠近（使用L2距离）。
        *   **切比雪夫奖励 $R_{cheb}$**：重点惩罚表现最差的维度（使用$L_\infty$距离）。
        最终奖励为两者加权和：$R_i = \alpha R_{ideal} + (1-\alpha)R_{cheb}$。
    4.  **组内优势估计**：对同一个原始提示生成的$K$个候选奖励进行组内归一化，计算相对优势 $A_i$，以减少绝对评分偏差。
    5.  **策略更新**：采用**组序列策略优化（GSPO）** 算法更新VLM参数，该算法带有序列级别的裁剪和KL散度正则化，损失函数为 $L_{SR}$。
